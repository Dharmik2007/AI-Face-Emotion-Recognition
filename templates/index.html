CNN vs CNN + LSTM Spatiotemporal Comparison

An educational and architectural exploration of Spatial Single-Frame Analysis vs. Temporal Sequence Recurrence.

Mode A: Deep Convolutional Neural Network (CNN) Active • Trained

Spatial Facial Feature Extraction

Processes individual static 48×48 grayscale facial patches independently. Hierarchical 2D convolutional kernels detect edges, textures, and geometric contours of facial action units (mouth curves, eyebrow dips).

  • Input: Single 48×48×1 Normalized Tensor
  • Receptive Field: Static 2D spatial pixel grid
  • Internal Latent Vector: 256-D intermediate embedding (Dense FC)
  • Strengths: Low computational complexity (~18 ms), fast response, excellent on posed static imagery
  • Limitations: Vulnerable to single-frame blinks, motion flutter, or transient micro-occlusions
Mode B: Spatiotemporal CNN + LSTM {% if lstm_available %} Active • Trained {% else %} Pipeline Ready • Awaiting Video Dataset {% endif %}

Temporal Sequence Recurrence

Combines the CNN's 256-D spatial feature extractor with a recurrent Long Short-Term Memory (LSTM) network over a sliding window of 16 consecutive frames, capturing natural onset, peak, and decay phases of expressions.

  • Input: 16 × 256-D sequence of CNN intermediate vectors
  • Recurrent Memory: 128 LSTM units with Input, Forget, and Output gates
  • Temporal Window: Sliding FIFO sequence buffer (~3.6 seconds at 4.5 FPS)
  • Strengths: Filters out transient blinks, dampens rapid flutter, models dynamic emotional transitions
  • Limitations: Sequence buffer warming required (must collect 16 frames before temporal prediction)
